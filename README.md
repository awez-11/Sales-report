# Sales Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes business sales performance across regions, categories, and customer segments.

## Key KPIs
- Total Sales
- Total Profit
- Total Quantity
- Total Discount

## Features
- Sales by Region
- Sales by City
- Sales by Segment
- Order Date Analysis
- Sub-Category Performance

## Tools Used
- Power BI
- DAX
- Excel

## Key Insights
- West region generated highest sales
- Consumer segment contributed maximum revenue
- Phones and Chairs were top-selling sub-categories
